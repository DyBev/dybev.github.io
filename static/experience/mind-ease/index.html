Mind Ease

Engineer

London, UK

Mind Ease was my first Software engineering role, joining as a second developer on a small mobile app that had a goal of making mental health easier to manage for people with busy lives by using CBT techniques to help them learn about why they feel the way they do and what they can do to combat these feelings

The company was a part of a wider incubator which also included Guided Track so we used Guided track to build out the app and it worked really well as there was minimal coding involved in getting new exercises and the layout and structure of the pages was largely solved for us

If we wanted extra functionality to the activities that we built we would need to make use of HTML/CSS and JS which we had access too because the app was run via a Cordova wrapper to display the app as a native application

The role really taught me a lot about innovating within a constrained environment and that CSS is much more powerful that we give it credit to, as we made heavy use of ::before and ::after elements to provide a richer UI to our users
